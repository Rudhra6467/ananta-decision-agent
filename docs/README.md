## Start of every lab day

1. Read charter limits (slots ≤ 6 preferred, enabled ≤ 5).
2. `git pull` + run agent.
3. `monitor` → `status`.
4. Follow daily ritual in the charter.
5. Update JOURNAL + SCOREBOARD before closing the laptop.
